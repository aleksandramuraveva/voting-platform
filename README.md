# Описание

## Функционал
### Frontend
- Блокировка кнопки после голосования и также всех кнопок при достижении лимита в 10 голосов
- Показываем юзеру сколько голосов у него осталось
- Анимированный индикатор загрузки идей
- Обработка и отображение ошибок 
- Полностью адаптивный интерфейс
- 

### Backend
- Обрабатка заголовока X-Forwarded-For и нормализация IP
- Проверка, не превысил ли данный IP-адрес лимит в 10 голосов
- При превышении лимита и последующих попытках голосовать мы отправляем 409 и заносим IP в in-memory блок с TTL чтобы не грузить БД (В реальных условиях можно использовать Redis)
- Также при более чем 20 запросов в минуту мы выдаем ошибку 429 Too Many Requests
- MySQL транзакции, индексирование
- Реализовала отдельную таблицу с подсчетом голосов каждого IP в которой блокируем строку IP пока идет проверка чтобы избежать race condition. Как итог только один IP ждёт свою строку, другие IP обрабатываются параллельно, остальная таблица не блокируется
- CORS с white-list настройкой
- Обработка ошибок и исключений

### Инфраструктура  
- Конфигурация через .env файлы
- Полная TypeScript поддержка
= Использовались Prettier, Lint

## Структура проекта

```
voting-platform/
  backend/   ← сервер на Node.js (Express + TypeScript + MySQL)
  frontend/  ← клиент на React (Vite + TypeScript)
```




#  Инструкции по запуску

### Для запуска проекта необходимо:

- Node.js: версия >= 20 
- npm: версия >= 10
- MySQL: версия >= 8.0




### Запуск локально
1. Клонировать репозиторий

   ```bash
   git clone https://github.com/aleksandramuraveva/voting-platform.git
   cd voting-platform
   ```

2. Создайте базу данных MySQL:
  ```sql
  CREATE DATABASE logiclike_voting;
  ```
❗Убедитесь, что MySQL сервер запущен и доступен локально (порт 3306 по умолчанию)

3. Настроить окружение
   * В папках `backend/` и `frontend/` есть файлы `.env.sample`
   * Скопируйте их и переименуйте в `.env`
   * Укажите свои значения по необходимости (особенно DB_PASSWORD для БД)

4. Установка зависимостей

   ```bash
   cd backend && npm install
   cd ../frontend && npm install
   ```

5. Запуск проектов
   * Бэкенд:

     ```bash
     cd backend
     npm run dev
     ```

     Сервер поднимется на `http://localhost:5000`
     🟥 База данных заполнится автоматически при первом запуске,проверяйте логи в консоли.

   * Фронтенд:

     ```bash
     cd frontend
     npm run dev
     ```

     По умолчанию на `http://localhost:5173`
